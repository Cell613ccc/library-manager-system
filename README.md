# 图书管理系统

## 项目概述

本项目旨在开发一款适配校园场景的图书管理系统，解决图书借阅管理、馆藏资源统计、校园阅读活动组织等问题，目标用户为全体在校师生及图书管理工作人员。

---

## 功能介绍

### ① 用户管理

实现用户注册、账号登录、个人信息维护、密码修改等功能，支持区分学生、教师、管理员等不同角色，赋予相应操作权限。

### ② 图书借阅

支持图书检索、借书、还书、续借、预约等功能，自动记录借阅时间与应还日期，提供逾期提醒与借阅历史查询。

### ③ 馆藏管理

管理员可进行图书入库、信息编辑、下架处理，支持按分类、作者、出版社等多维度统计馆藏资源，生成馆藏报表。

### ④ 排行榜与阅读成就

按借阅量、阅读时长等维度展示年级/班级阅读排行榜，设置阅读成就体系，如“阅读之星”“博览群书”等，并发放荣誉标识。

### ⑤ 社交与分享

支持用户发布读书笔记、书评动态，可将阅读记录、书评内容分享至好友或班级群，促进阅读交流与文化氛围营造。

技术栈：前端使用Vue3，后端使用SpringBoot，数据库采用MySQL，接口文档使用Swagger
